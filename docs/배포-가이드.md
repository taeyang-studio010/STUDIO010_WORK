# STUDIO 010 배포하기 (처음 보는 사람도 따라 할 수 있게)

**배포** = 지금은 내 컴퓨터에서만 보이던 웹을, **인터넷 주소**로 열 수 있게 만드는 거예요.  
아래 순서대로만 하면 됩니다.

---

## 준비물

- GitHub 계정 (없으면 https://github.com 에서 무료 가입)
- Vercel 계정 (나중에 GitHub로 로그인하면 됨)
- 이미 해 둔 것: Supabase 프로젝트, .env.local 에 넣었던 주소·키 3개

# 1단계: GitHub에 코드 올리기

**GitHub** = 코드를 인터넷에 올려 두는 곳이에요.  
나중에 Vercel이 여기서 코드를 가져가서 웹으로 만들어 줍니다.

### 1-1. GitHub에 새 창고(저장소) 만들기

1. 브라우저에서 **https://github.com** 들어가서 로그인
2. 오른쪽 위 **+** 버튼 클릭 → **New repository** 클릭
3. **Repository name**에 아무 이름 입력 (예: `studio010`)
4. **Public** 선택
5. **Create repository** 버튼 클릭
6. 화면이 바뀌면 **창고가 만들어진 거예요.** 그 화면은 나중에 쓰니까 그대로 두세요.

### 1-2. Cursor에서 터미널 열기

1. Cursor 맨 위 메뉴에서 **Terminal** → **New Terminal** 클릭
2. 아래쪽에 검은 창(터미널)이 뜹니다.

### 1-3. 터미널에 명령어 넣기 (한 줄씩 엔터)

아래를 **한 줄씩** 복사해서 터미널에 붙여 넣고 **엔터** 치세요.

```text
cd /Users/sun_brother/Documents/studio-010-workspace
```

```text
git init
```

```text
git add .
```

```text
git commit -m "첫 배포"
```

(여기까지 하면 “커밋이 완료됐다” 같은 말이 나올 수 있어요. 정상이에요.)

### 1-4. GitHub 창고랑 연결하기

1. 아까 만들어 둔 **GitHub 창고 페이지**로 가세요.
2. 거기 보이는 **주소**를 복사하세요.  
   (예: `https://github.com/내아이디/studio010.git` 같은 형태)
3. 터미널에 아래를 넣되, **한가지만 바꿔 주세요.**  
   `https://github.com/내아이디/studio010.git` 부분을 **본인 창고 주소**로요.

```text
git remote add origin https://github.com/내아이디/studio010.git
```

4. 그 다음 이걸 입력하고 엔터:

```text
git branch -M main
```

```text
git push -u origin main
```

5. **GitHub 아이디·비밀번호(또는 토큰)** 물어보면 입력하고 엔터.  
   끝나면 **1단계 완료**예요. GitHub 창고 페이지를 새로고침하면 파일들이 보일 거예요.

# 2단계: Vercel 가입하고 프로젝트 만들기

**Vercel** = GitHub에 올린 코드를 가져가서 **웹 주소**를 만들어 주는 서비스예요.

### 2-1. Vercel 들어가기

1. 브라우저에서 **https://vercel.com** 접속
2. **Sign Up** 클릭
3. **Continue with GitHub** 선택해서 GitHub로 로그인 (이렇게 하면 나중에 창고 고르기 쉬워요)

### 2-2. 새 프로젝트 만들기

1. 로그인되면 **Add New…** 버튼 클릭 → **Project** 클릭
2. **Import Git Repository** 안에 **방금 올린 창고 이름**이 보일 거예요. (예: studio010)
3. 그 옆 **Import** 버튼 클릭

### 2-3. 환경 변수 3개 넣기 (중요)

**환경 변수** = “웹이 돌아갈 때 필요한 비밀 번호 같은 것”이라고 생각하면 돼요.  
Supabase 쓸 때 쓰는 값 3개를 여기 한 번 더 넣어 줘야 해요.

1. **Configure Project** 화면이 나오면, 아래로 내려서 **Environment Variables** 부분을 찾으세요.
2. **Name** 이랑 **Value** 를 넣는 칸이 있어요. 아래 **3개**를 하나씩 넣으세요.

**첫 번째**

- Name: `NEXT_PUBLIC_SUPABASE_URL`
- Value: Supabase에서 복사한 **Project URL** (예: https://xxxxx.supabase.co)

**두 번째**

- Name: `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- Value: Supabase에서 복사한 **anon public** 키 (긴 글자)

**세 번째**

- Name: `SUPABASE_SERVICE_ROLE_KEY`
- Value: Supabase에서 복사한 **service_role** 키 (Reveal 눌러서 보이게 한 다음 복사)

> Supabase에서 복사하는 곳: Supabase 대시보드 → ⚙️ **Project Settings** → **API**  
> 거기 보이는 **Project URL**, **anon public**, **service_role** 을 그대로 복사해서 위 Value 자리에 넣으면 됩니다.

3. 세 개 다 넣었으면 **Deploy** 버튼 클릭

### 2-4. 배포 끝날 때까지 기다리기

1. **Building…** 이라고 나오면서 진행돼요. 1~2분 정도 기다리세요.
2. **Congratulations** 같은 문구가 나오면 **배포 완료**예요.
3. **Visit** 버튼을 누르거나, **Your Project** 같은 링크를 누르면 **우리 웹이 열리는 주소**가 나와요.  
   예: `https://studio010-xxxxx.vercel.app`  
   이 주소를 **메모장에 복사해 두세요.** 나중에 쓸 거예요.

# 3단계: Supabase에 “우리 웹 주소” 알려 주기

지금 만든 **웹 주소**에서 로그인·회원가입이 되려면, Supabase한테 “이 주소도 허용해 줘”라고 등록해 줘야 해요.

### 3-1. Supabase 설정 화면으로 가기

1. **https://supabase.com/dashboard** 접속해서 로그인
2. 사용 중인 **프로젝트** 클릭
3. 왼쪽 메뉴에서 **Authentication** 클릭
4. 그다음 **URL Configuration** 클릭

### 3-2. Redirect URLs에 주소 추가하기

1. **Redirect URLs** 라는 칸을 찾으세요.
2. 이미 뭔가 적혀 있어도 **한 줄 더 추가**해 주세요.  
   아래에서 `여기에배포주소` 만 **2단계에서 메모한 주소**로 바꿔서 넣으면 됩니다.  
   (예: `https://studio010-xxxxx.vercel.app` 이라면, `https://` 와 `.vercel.app` 는 그대로 두고 가운데만 본인 걸로.)

첫 번째 줄 추가:

```text
https://여기에배포주소.vercel.app/auth/callback
```

두 번째 줄 추가:

```text
https://여기에배포주소.vercel.app/**
```

3. **Save** 버튼 클릭

### 3-3. Site URL 바꾸기 (선택)

- **Site URL** 이라는 칸이 있으면, 거기를 **배포 주소**로 바꿔도 돼요.  
  예: `https://studio010-xxxxx.vercel.app`  
- 바꾼 다음 **Save** 한 번 더 누르세요.

# 4단계: 실제로 들어가서 확인하기

1. 브라우저 주소창에 **메모해 둔 배포 주소**를 넣고 엔터 (예: https://studio010-xxxxx.vercel.app)
2. **로그인 화면**이 뜨면 성공이에요.
3. **호스트(처음 관리자)** 로 가입하려면 주소 맨 뒤에 `/signup?host=1` 을 붙여서 들어가세요.  
   예: `https://studio010-xxxxx.vercel.app/signup?host=1`  
   거기서 회원가입하면 돼요.

# 끝: 한 번에 정리

1. **GitHub** 에 코드 올리기 (창고 만들고 → 터미널에서 git 명령어)
2. **Vercel** 에서 GitHub 창고 가져와서 **Deploy** (환경 변수 3개 꼭 넣기)
3. 나온 **웹 주소**를 **Supabase** → Authentication → URL Configuration 에 추가

나중에 **내가 원하는 주소(도메인)** 로 바꾸고 싶으면, 그때 Vercel **Domains** 설정을 하면 됩니다.
