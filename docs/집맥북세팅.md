# 집 맥북 세팅 가이드

새 맥북에서 STUDIO 010 워크스페이스를 돌리기 위한 순서입니다.

---

## 1. macOS 기본 도구

### Xcode Command Line Tools (git 포함)

```bash
xcode-select --install
```

- 팝업에서 **설치** 선택 후 완료될 때까지 대기  
- 확인: `git --version`

---

## 2. Node.js 설치

### 옵션 A: nvm (권장 — 버전 전환 용이)

```bash
# nvm 설치 (공식 스크립트)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# 터미널 재시작 후
nvm install 20
nvm use 20
node -v   # v20.x.x
npm -v
```

### 옵션 B: 공식 인스톨러

- https://nodejs.org 에서 LTS 다운로드 후 설치  
- 확인: `node -v`, `npm -v`

---

## 3. Homebrew (선택)

패키지/도구 관리용.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# 설치 후 안내에 따라 PATH 추가 (예: echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile)
brew --version
```

---

## 4. Docker (로컬 Supabase용)

로컬에서 Supabase를 쓰려면 Docker 필요.

- https://www.docker.com/products/docker-desktop/  
- **Docker Desktop for Mac** (Apple Silicon이면 ARM 버전) 설치  
- 설치 후 앱 실행 → 상단 메뉴에서 Docker가 켜진 상태인지 확인  
- 확인: `docker --version`, `docker ps`

---

## 5. 프로젝트 준비

### 5.1 저장소 복사 (이미 있는 경우 생략)

- 이 워크스페이스가 Git 저장소라면: `git clone <저장소 URL>` 로 원하는 폴더에 복사  
- 이미 `studio-010-workspace` 폴더를 쓰는 경우 그대로 진행

### 5.2 의존성 설치

```bash
cd /Users/sun_brother/Documents/studio-010-workspace
npm install
```

### 5.3 환경 변수

프로젝트 루트에 `.env.local` 생성:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

- Supabase 대시보드 → 프로젝트 설정 → API에서 값 복사  
- 로컬 Supabase만 쓸 경우 `npm run supabase:start` 후 터미널에 출력되는 URL/키 사용

---

## 6. 로컬 Supabase (선택)

Docker 실행 후:

```bash
npm run supabase:start
npm run supabase:db:reset
```

- `.env.local`에는 Supabase CLI가 안내하는 로컬 URL/키 입력

---

## 7. 개발 서버 실행

```bash
npm run dev
```

- 브라우저: http://localhost:3000

---

## 8. 에디터 (선택)

- **Cursor** 또는 **VS Code** 설치  
- 이 폴더를 워크스페이스로 열기

## 체크리스트 요약

| 단계 | 항목 | 확인 |
|------|------|------|
| 1 | Xcode Command Line Tools | `git --version` |
| 2 | Node.js (v18+ 권장) | `node -v`, `npm -v` |
| 3 | Homebrew (선택) | `brew --version` |
| 4 | Docker (로컬 Supabase용) | `docker ps` |
| 5 | `npm install` | `node_modules` 존재 |
| 6 | `.env.local` 작성 | Supabase URL/키 입력 |

---

## 문제 해결

- **`npm install` 실패**: Node 버전 18 이상인지 확인 (`node -v`)
- **Supabase 연결 실패**: `.env.local` 키/URL 오타, Supabase 프로젝트 일시중지 여부 확인
- **Docker 오류**: Docker Desktop이 실행 중인지, 권한/리소스 제한 확인

이 순서대로 진행하면 집 맥북에서 STUDIO 010 개발 환경 세팅을 마칠 수 있습니다.
