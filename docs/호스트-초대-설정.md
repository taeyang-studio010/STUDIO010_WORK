# 호스트 전용 · 초대 가입 설정

조태양님만 호스트(관리자)이고, 나머지 멤버는 **호스트가 보내는 초대 메일**로만 가입할 수 있도록 설정하는 방법입니다.

---

## 1. 호스트(조태양님)가 할 일

### ① 호스트 회원가입 완료

- **아직 회원가입을 안 하셨다면**  
  → 브라우저에서 아래 주소로 들어가서 **호스트 전용 회원가입 폼**을 엽니다.  
  **http://localhost:3000/signup?host=1**  
  (실제 서비스 주소가 있으면 그 주소로 바꿔서 `/signup?host=1` 로 들어가면 됩니다.)  
  → **이름·이메일(taeyang@studio010.kr)·비밀번호** 입력 후 **「회원가입」** 버튼을 눌러 가입을 완료하세요.
- 가입 후 이메일 확인 링크가 오면, 링크를 눌러서 **이메일 인증**까지 해 두세요.
- **일반 회원가입 주소(/signup)에는** “초대로만 가입 가능” 안내만 보이고, 가입 폼은 나오지 않습니다. 호스트만 `?host=1` 로 들어가서 한 번만 가입하면 됩니다.
- 이미 가입하셨다면 이 단계는 건너뛰면 됩니다.

### ② DB에 호스트로 등록 (마이그레이션 적용)

- 터미널에서 아래 명령을 실행해서, `taeyang@studio010.kr` 계정을 **호스트(관리자)** 로 등록합니다.

```bash
cd /Users/sun_brother/Documents/studio-010-workspace
npm run supabase:db:push
```

- (로컬 Supabase가 아니라 **Supabase 클라우드**를 쓰는 경우)  
  Supabase 대시보드 → **SQL Editor**에서 아래 SQL을 실행해도 됩니다.

```sql
update public.profiles
set is_exec = true, updated_at = now()
where email = 'taeyang@studio010.kr';
```

- 이렇게 하면 **조태양님만** 초대 메일을 보낼 수 있는 호스트가 됩니다.

### ③ Supabase에서 “누구나 가입” 끄기

- [Supabase 대시보드](https://supabase.com/dashboard) 로그인 후, 사용 중인 **프로젝트** 선택.
- 왼쪽 메뉴 **Authentication** → **Providers** 클릭.
- **Email** 선택.
- **“Enable email signups”** (이메일로 회원가입 허용)를 **OFF**로 바꾼 뒤 저장.

이렇게 하면:

- **호스트(조태양님)** 는 이미 가입한 계정으로 로그인 가능.
- **다른 사람**은 호스트가 초대한 경우에만, 초대 메일 링크로 비밀번호 설정 후 가입·로그인 가능.

---

## 2. 다른 멤버 초대하는 방법 (호스트만 가능)

1. 호스트 계정(taeyang@studio010.kr)으로 **로그인**.
2. 왼쪽 **사이드바 맨 아래**의 **「임원 초대」** 칸에서  
   - 초대할 사람 **이메일**, **이름(선택)**, **역할** 입력.
3. **「초대 메일 전송」** 클릭.

→ 초대받은 사람 이메일로 **Supabase 초대 메일**이 갑니다.  
→ 받은 사람이 메일 안의 **링크**를 누르면 **비밀번호 설정** 후 가입·로그인할 수 있습니다.

---

## 3. 정리

| 역할       | 가입 방법                         | 초대 보내기 |
|-----------|-----------------------------------|------------|
| 호스트(조태양) | 회원가입 화면에서 1회 가입 후 로그인 | ✅ 가능     |
| 나머지 멤버   | 호스트가 보낸 초대 메일 링크로만 가입 | ❌ 불가     |

- **호스트만** “임원 초대”로 로그인 허가 이메일을 보낼 수 있고,  
- **나머지는** 그 이메일로 승인(비밀번호 설정) 후에만 진행할 수 있도록 되어 있습니다.
