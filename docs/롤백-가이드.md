# 롤백 가이드 – v0.1로 되돌리기

**STUDIO010_work v.01** = 반응형 적용 전, 현재 마음에 드시던 웹 버전입니다.  
다녀와서 반응형 버전이 맘에 안 들면 아래대로 하면 v0.1 상태로 되돌릴 수 있어요.

---

## v0.1이 뭔가요?

- **태그 이름:** `v0.1`
- **의미:** 반응형 작업 직전 시점의 코드(웹)를 저장해 둔 버전
- **롤백** = 이 버전으로 코드를 되돌리는 것

---

## 롤백 방법 (로컬에서)

터미널에서 프로젝트 폴더로 이동한 뒤:

```bash
cd /Users/sun_brother/Documents/studio-010-workspace

# 1) v0.1 시점으로 되돌리기 (main 브랜치를 v0.1 상태로 덮어씀)
git fetch origin
git reset --hard v0.1

# 2) 이미 push한 반응형 커밋을 원격에서도 되돌리고 싶다면 (주의: main 히스토리가 바뀜)
git push origin main --force
```

- **`git reset --hard v0.1`** 만 하면: 내 컴퓨터만 v0.1로 돌아가고, GitHub/Vercel은 그대로임.  
- **`git push origin main --force`** 까지 하면: GitHub·Vercel까지 v0.1로 맞추는 거라, 반응형 커밋이 사라짐.

---

## v0.1만 확인하고 싶을 때 (롤백은 안 하고)

```bash
git checkout v0.1
# 코드 보거나 실행해 보기
git checkout main   # 다시 main으로
```

---

## 요약

| 하고 싶은 것           | 명령 |
|------------------------|------|
| 로컬만 v0.1로 되돌리기 | `git reset --hard v0.1` |
| 원격(main)까지 v0.1로  | `git reset --hard v0.1` 후 `git push origin main --force` |
| v0.1만 잠깐 보기       | `git checkout v0.1` → 볼 때만 사용 후 `git checkout main` |

다녀와서 맘에 안 들면 위대로 롤백하시면 됩니다.
